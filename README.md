# flyrank-05
## Target classification

**Site:** books.toscrape.com
**Scope:** first 3 catalogue pages, then all book detail pages linked from them (60 books)
**robots.txt result:** Requested https://books.toscrape.com/robots.txt — returned 404 (no robots file exists).
A missing file is not permission on its own.
**Why this is appropriate:** books.toscrape.com states on its own page that it is a sandbox built
specifically for people to practice web scraping. That explicit self-description is what
makes scraping it appropriate here — not the absence of a robots.txt file.
**Data collected:** book title, price, availability, rating, description, and product URL —
publicly displayed catalogue data, nothing behind a login.

I will not reuse this code on another site without checking its rules and terms first.
